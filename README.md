# 🏥 MedBook Dental Assistant

A premium, AI-powered dental appointment booking system featuring a bilingual voice assistant, real-time schedule management, and a dedicated provider dashboard.

---

## ✨ Key Features

* **🎙️ AI Voice Assistant:** Interactive booking flow using ElevenLabs for high-fidelity speech and Web Speech API for real-time transcription.
* **🌐 Bilingual Support:** Seamlessly switch between English and Hindi voice/text commands.
* **📅 Dynamic Scheduling:** Doctors can mass-generate slots across custom date ranges or manage individual appointments via a Bento-style calendar.
* **📱 Responsive Design:** Fully optimized "Aqua Sanctuary" mobile experience and a sophisticated dual-column desktop dashboard.
* **🔐 Secure Admin Portal:** Protected provider access via Supabase Authentication.
* **⚡ Real-time Updates:** Instant UI refreshes using Supabase PostgreSQL listeners.

---

## 🛠️ Tech Stack

* **Frontend:** React (Vite), Tailwind CSS v4
* **Backend/Database:** Supabase (PostgreSQL)
* **Voice AI:** ElevenLabs API
* **Icons:** Material Symbols Outlined
* **Typography:** Noto Serif & Manrope
